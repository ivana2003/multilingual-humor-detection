# Multilingual Humor Detection

Official code repository for **“From Supervised Learning to LLMs: A Multilingual Study of Humor Detection”** by Ivana Crescenzi, Jakub Jerzy Górecki, Emanuele Moscato, and Debora Nozza (CLiC-it 2026).

This repository reconstructs the experimental design described in the final paper and separates the paper's published reference scores from results generated by this code. The original working archive contained duplicated HPC trees, preliminary experiments, stale configurations, and credentials; none of those structures or secrets are preserved here.

## Study overview

The study compares three model families for binary humor detection across five datasets:

| Code | Language | Dataset | Paper size | Humorous |
|---|---|---|---:|---:|
| `en` | English | CoMB | 45,488 | 62.2% |
| `es` | Spanish | Martínez Spanish jokes dataset | 2,419 | 63.1% |
| `pt` | Portuguese | Gonçalo Oliveira et al. combined corpus | 2,800 | 50.0% |
| `zh` | Chinese | HumorWB/Weibo | 5,291 | 38.0% |
| `hi_en` | Hindi-English | Khandelwal et al. code-mixed corpus | 2,949 | 59.6% |

Model families:

1. Logistic Regression and linear SVM with TF-IDF unigrams and bigrams.
2. Fine-tuned XLM-R and one language-specific encoder per dataset.
3. GPT-4o-mini and Qwen 2.5 7B Instruct with zero-shot and few-shot prompts.

## Installation

Python 3.11–3.13 is supported; Python 3.11 is recommended for the widest GPU-library compatibility.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

Transformer experiments:

```bash
python -m pip install -r requirements-transformers.txt
```

Qwen experiments additionally require a compatible CUDA installation and PyTorch build:

```bash
python -m pip install -r requirements-qwen.txt
```

OpenAI API experiments:

```bash
python -m pip install -r requirements-openai.txt
cp .env.example .env
# Set OPENAI_API_KEY in your shell or secret manager. Do not commit .env.
```

No code license was selected in the supplied material. A repository owner must choose one before broader reuse or redistribution of the code.

## Dataset preparation

Raw datasets are not included. Obtain each dataset from its official source and check its terms before use; see [`docs/DATASETS.md`](docs/DATASETS.md). Normalize a downloaded table with:

```bash
python scripts/prepare_data.py \
  --dataset es \
  --input /path/to/spanish.csv \
  --text-column text \
  --label-column rating
```

For Spanish, `prepare_data.py` applies the paper's mapping: rating 1 to label 0 and ratings 2 or 3 to label 1. For already-binary datasets, specify the text and label columns. The command verifies the expected total and the paper-reported class proportion, writes a normalized CSV to `data/processed/`, and creates a deterministic stratified 70/10/20 manifest in `data/splits/` with seed 42.

The archive did not contain the required raw datasets or a valid CoMB preparation manifest. Consequently, dataset acquisition must be completed before full reproduction.

## Run experiments

All commands assume `python -m pip install -e .` has been run.

### Traditional machine learning

```bash
python scripts/run_traditional_ml.py --dataset en --model lr
python scripts/run_traditional_ml.py --dataset en --model svm
```

Spanish SVM is intentionally unavailable in the primary runner because that cell is absent from Table 2. The implementation uses TF-IDF unigrams and bigrams, `min_df=2`, stratified 5-fold selection of `C` from `0.1, 1, 10`, final fitting on training plus validation, and held-out test macro-F1.

### Fine-tuned transformers

```bash
python scripts/run_transformers.py --dataset en --model xlm-r
python scripts/run_transformers.py --dataset en --model language-specific
```

Replace `en` with `es`, `pt`, `zh`, or `hi_en`. The second command resolves the language-specific model from `configs/transformers.yaml`.

### Qwen 2.5 7B Instruct

```bash
python scripts/run_llms.py --dataset zh --backend qwen --shot zero
python scripts/run_llms.py --dataset zh --backend qwen --shot few
```

Qwen requires a GPU with sufficient memory. The implementation uses deterministic generation (`do_sample=False`) and records that the paper reported “greedy decoding with temperature 0.1”; temperature has no operational effect under greedy decoding.

### GPT-4o-mini

API experiments can incur charges and are never started without an explicit command-line authorization flag. Before execution, the script prints the number of uncached requests.

```bash
# Configure OPENAI_API_KEY in the shell or an approved secret manager.
python scripts/run_llms.py \
  --dataset en \
  --backend openai \
  --shot few \
  --authorize-paid-api
```

Predictions are appended one record at a time to JSONL, raw responses are retained, parser failures are recorded, and cached requests are not sent again.

### Aggregate reproduced results

```bash
python scripts/aggregate_results.py
```

This reads completed `result.json` files, uses only `metrics.test.macro_f1`, writes `results/reproduced/table2_reproduced.csv`, and creates a difference report against the immutable paper table.

## Validation

```bash
pytest
python scripts/validate_repository.py
```

Validation compiles the code, checks YAML, scans for secrets and absolute personal paths, verifies the separation of reported and reproduced results, and confirms that imports do not start downloads, model training, or API calls. The completed construction-time checks are recorded in [`docs/VALIDATION_REPORT.md`](docs/VALIDATION_REPORT.md).

## Reported versus reproduced results

`results/paper/table2_reported.csv` is a transcription of Table 2 and is **not evidence of reproduction**. New experiment outputs belong under `results/reproduced/`. The audit of whether individual published cells can be traced to files in the raw archive is in `results/archive_evidence/table2_traceability.csv` and `docs/REPRODUCIBILITY_REPORT.md`.

## Hardware and external services

Traditional ML runs on CPU. Fine-tuned transformers were reported on one NVIDIA V100 or A100 with mixed precision when available. Qwen requires one sufficiently capable GPU. GPT-4o-mini requires network access, an OpenAI account, and user-authorized paid API calls.

## Reproducibility limits

The cleaned code follows the final paper as the scientific source of truth, but the supplied archive is not a complete executable provenance package. In particular, it lacks raw data, an actual CoMB preparation pipeline, complete paper-consistent split manifests, and unambiguous held-out-test evidence for several Table 2 cells. These limitations are documented rather than silently repaired.
